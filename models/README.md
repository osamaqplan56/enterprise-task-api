# Enterprise Task Management API

An advanced, asynchronous Task and Project Management API built with **FastAPI** and **SQLAlchemy**. Designed for remote software development teams to manage workflows using Role-Based Access Control (RBAC).

## 🚀 Features
- 🔐 **Authentication & Security:** Secure user registration with password hashing.
- 📁 **Project Management:** Create and structure long-term development projects.
- 🛠️ **Task Management:** Create, prioritize, and assign tasks to developers within projects.
- 📝 **Auto-Documentation:** Built-in interactive API documentation via Swagger UI.

## 🛠️ Architecture & Tech Stack
- **Framework:** FastAPI (Python)
- **Database ORM:** SQLAlchemy with SQLite/PostgreSQL
- **Data Validation:** Pydantic v2
- **Server:** Uvicorn
